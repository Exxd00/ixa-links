# IXA Links Hub

Eine schnelle, responsive Link-in-Bio-Seite für IXA.

## Inhalte anpassen

Die Linkziele und Texte stehen direkt in `index.html`. Vor der Veröffentlichung bitte besonders die Platzhalter-Telefonnummer in den Links `tel:` und `wa.me` ersetzen.

Zum lokalen Starten genügt ein statischer Webserver, zum Beispiel `npx serve .`.
